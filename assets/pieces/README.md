# 말(플레이어 토큰) 사진 넣는 곳

아래 4개 파일을 이 폴더에 그대로 넣으면 게임이 자동으로 사진을 씁니다.
파일이 없으면 이모지(🧒 👨 👩 🐻)가 대신 표시됩니다.

| 파일명 | 말 | 색 |
|---|---|---|
| `siu.png` | 시우 (말 1) | 주황 |
| `dad.png` | 아빠 (말 2) | 파랑 |
| `mom.png` | 엄마 (말 3) | 초록 |
| `friend.png` | 친구 (말 4) | 노랑 |

## 사진 권장 사양
- 정사각형 (1:1), 512×512 이상
- 배경 투명 PNG (원형으로 잘려서 표시됨)
- 인물/캐릭터가 가운데 오도록

파일명·개수·색을 바꾸려면 `data/pieces.js` 를 수정하세요.
